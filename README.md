## What's this?

I'm learning German and want to learn it pretty fast, which means cramming a lot of practice with mainly vocab but also grammar and inflections and stuff

To this end this is a little CLI application with the following:

#### Wordlist files I can write and organise in plain text
- Definitions for a german word or phrase can have multiple associated translations + labels/notes
- Nouns are tagged with gender, plural if they have them (plural is also a gender and nouns can be plural-only)
- Verbs are tagged with if I should learn the conjugations in present/simple past/past participle/imperative etc
- Automatic checking for duplicates, etc
- Tagging verbs and nouns with the extra data is optional at first, I am reminded of my "chores" once the flashcards progress enough

As a result I can jot down words I hear from anywhere i.e. `Hund = dog` into my phone notes or whatever and then paste it into the wordlist files

I can leave time-debt for later and then look up the gender and plural forms when I'm sat at my desk

#### Flashcard system a bit like Anki
- Simpler algorithm than Anki, closer to the Leitner Method
- Tiered cards can "unlock" once the previous card progresses
  e.g. recognise english from german -> recall german from english -> again with gender -> again with plural

#### Other practice tools
- A bunch of hand-coded exercises for cases and declension and all that good stuff
- Separate specialised flashcard mode for verbs
